This report explores bike share data to understand the differences between members and casual riders.
We will focus on usage patterns such as ride duration, time of day, station popularity, and distance traveled.
The goal is to provide insights that can help increase membership rates.

This study hopes to inform marketing campaigns by providing data insights that focus on the differences between Casual users of the bike share app and Members

Setup

In the ask phase of the data analysis we need to look at the current position that the bike share app has found itself in. we need to find context that we can work with later in out analysis

The company in question is Bike share. There company model is based on public use bicycles. Bike share offers both a casual model and a subscription model. The company is commited to inclusivity of bikes offering docked bikes.

The data has been sourced from the Google Coursera Dataset. Due to the size of the entire dataset we have narrowed down our analysis to focus on the full year of 2022

Some key questions to ask include

-How do casual riders differ in the time and location of bike usage compared to members?

-What patterns can we find about casual and membership users and can this be used in a marketing campaign?

-Are there any trends over time that we can explore?

Assumptions and limitations

There are some key limitations with the data. The main limitation of this analysis is that its only focusing on the year 2022. This is due to the size of the data set and the power of my computer while focusing on one year can give a good overview of the bike usage it is important to note that a larger dataset could provide more accurate insights than this analysis

Feature engineering, prepare phase

During this phase we will mutate and modify the data so it is easier to use when plotting analysis. The main area of change is adding new columns for important sets of information on casual and members style users We will create new columns for ; start month, weekday, hour and end hour Using these columns we can learn more about key parts of the data that otherwise couldn’t be used

# feature engineering

df_bikes$ride_duration <- round(as.numeric(difftime(df_bikes$ended_at,df_bikes$started_at,units = "mins")))
df_bikes$month <- month(df_bikes$started_at,label=TRUE)
df_bikes$wday <- wday(df_bikes$started_at,label=TRUE)
df_bikes$start_hour <- hour(df_bikes$started_at)
df_bikes$end_hour <- hour(df_bikes$ended_at)

# Haversine distance (km)
df_bikes$trip_distance_km <- distHaversine(
  cbind(df_bikes$start_lng, df_bikes$start_lat),
  cbind(df_bikes$end_lng, df_bikes$end_lat)

Top 10 start stations

top_stations_counts <- df_bikes %>%
  filter(!is.na(start_station_name)) %>%
  group_by(start_station_name, membership_type) %>%
  summarise(trip_count = n(), .groups = "drop")

top_stations <- top_stations_counts %>%
  group_by(start_station_name) %>%
  summarise(total_trips = sum(trip_count)) %>%
  arrange(desc(total_trips)) %>%
  slice_head(n = 10) %>%
  pull(start_station_name)

top_stations_data <- top_stations_counts %>%
  filter(start_station_name %in% top_stations) %>%
  mutate(start_station_name = factor(start_station_name, levels = rev(top_stations)))

ggplot(top_stations_data, aes(x = start_station_name, y = trip_count, fill = membership_type)) +
  geom_col(position = "dodge") +
  coord_flip() +
  labs(title = "Top 10 Start Stations by Membership Type",
       x = "Start Station Name",
       y = "Number of Trips",
       fill = "Membership Type") +
  scale_fill_brewer(palette = "Set2") +
  theme_minimal()

Looking at the top stations that bikes are used from we can see that the largest usage is at Streeter Dr & grand avenue. However the numbers show that the majority of bikes here are used by casual members. This is likely due to it being a tourist hotspot in the city. Those stations that have higher membership usage are likely areas that commuters use more. This could be due to location or due to the reliability of bike availability and can be looked into further for more Analysis.

Marketing could be done around the busy tourist stations promoting memberships as this is where the majority of casual members are using the bikes.

Key takeaways and reccomendations for increasing the number of subscribers

  • Promoting riding incentives for casual members during the winter months. Offer discounts or rewards to those that ride in the winter
  • Promote subscriberships at key bike stations where the usage of bikes is largley dominated by casual users
  • Promote membership saving to those casual users that use bikes regulary each month. Those that can save by using a membership are likely to switch. However without a promotion many will miss out on these savings
  • promote weekday riding to casual members are there is a large drop off during the week
  • Promoting and offering deals to those that commute daily can lead to an increase in memberships. Promoting on other public transport could target the key demographic of those that are commuting on weekdays to and from work on another mode of transport
