Bike Share Analysis

Oliver Dickinson
2025-09-07

This report explores bike share data to understand the differences between members and casual riders. We will focus on usage patterns such as ride duration, time of day, station popularity, and distance traveled. The goal is to provide insights that can help increase membership rates.

This study hopes to inform marketing campaigns by providing data insights that focus on the differences between Casual users of the bike share app and Members

Setup

In the ask phase of the data analysis we need to look at the current position that the bike share app has found itself in. we need to find context that we can work with later in out analysis

The company in question is Bike share. There company model is based on public use bicycles. Bike share offers both a casual model and a subscription model. The company is commited to inclusivity of bikes offering docked bikes.

The data has been sourced from the Google Coursera Dataset. Due to the size of the entire dataset we have narrowed down our analysis to focus on the full year of 2022

Key Questions

  • How do casual riders differ in the time and location of bike usage compared to members?
  • What patterns can we find about casual and membership users and can this be used in a marketing campaign?
  • Are there any trends over time that we can explore?
Assumptions and Limitations

There are some key limitations with the data. The main limitation of this analysis is that its only focusing on the year 2022. This is due to the size of the data set and the power of my computer while focusing on one year can give a good overview of the bike usage it is important to note that a larger dataset could provide more accurate insights than this analysis

Feature Engineering

During this phase we will mutate and modify the data so it is easier to use when plotting analysis. The main area of change is adding new columns for important sets of information on casual and members style users. We will create new columns for; start month, weekday, hour and end hour. Using these columns we can learn more about key parts of the data that otherwise couldn't be used.

# Feature engineering df_bikes$ride_duration <- round(as.numeric(difftime(df_bikes$ended_at,df_bikes$started_at,units = "mins"))) df_bikes$month <- month(df_bikes$started_at,label=TRUE) df_bikes$wday <- wday(df_bikes$started_at,label=TRUE) df_bikes$start_hour <- hour(df_bikes$started_at) df_bikes$end_hour <- hour(df_bikes$ended_at) # Haversine distance (km) df_bikes$trip_distance_km <- distHaversine( cbind(df_bikes$start_lng, df_bikes$start_lat), cbind(df_bikes$end_lng, df_bikes$end_lat) ) / 1000

Analysis Phase

Using the data we have modified we can now plot some key metrics. We will be focusing only on comparing the casual memberships with the member users as this is key to our business objective.

Trips per Hour

Hourly Trip Distribution by Membership Type
Histogram showing peak usage times for casual vs member riders
Key Insights - Hourly Usage

From this plot we can see some key insights into differences between membership types. While the plot shows steady usage from midnight to 5am, there is a sharp spike of usage from Subscription members between the hours of 5:30am - 9am and between 4pm - 6/7pm.

Marketing Opportunities:

  • Discount bikes during twilight hours due to minimal usage
  • Promote commuter benefits to casual riders during peak hours
  • Target promotional efforts highlighting work commute usage

Trips per Month

Monthly Trip Distribution by Membership Type
Seasonal usage patterns throughout 2022
Seasonal Insights

We can see a clear trend that the numbers of casual riders decreases during the colder months. While subscribers decrease towards December and remain low towards February, they maintain much higher usage than casual users.

Winter Marketing Strategies:

  • Offer loyalty discounts to casual members during colder months
  • Bundle winter rides with perks like hot drink coupons
  • "Ride all winter for $x" promotional campaigns

Key Takeaways and Recommendations for Increasing Subscribers
  • Promoting riding incentives for casual members during the winter months. Offer discounts or rewards to those that ride in the winter
  • Promote subscriptions at key bike stations where the usage of bikes is largely dominated by casual users
  • Promote membership savings to those casual users that use bikes regularly each month. Those that can save by using a membership are likely to switch
  • Promote weekday riding to casual members as there is a large drop off during the week
  • Promoting and offering deals to those that commute daily can lead to an increase in memberships. Promoting on other public transport could target the key demographic of commuters
